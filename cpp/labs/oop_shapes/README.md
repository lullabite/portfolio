# OOP: Cube, Prism, Parallelepiped

Классы `Cube`, `Prism`, `Parall` с методами `input()`
и `surface_area()` - вычисление полной площади поверхности куба, правильной
четырёхугольной призмы и прямоугольного параллелепипеда.

**Технологии:** C++, классы, инкапсуляция

## Запуск

```bash
g++ main.cpp -o oop_shapes
./oop_shapes
```
