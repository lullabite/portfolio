# Operator Overload: Vector Cross Product

Лабораторная работа: перегрузка оператора `&` для структуры `Vector` -
вычисление векторного произведения `[Y1*Z2-Y2*Z1, Z1*X2-Z2*X1, X1*Y2-X2*Y1]`.

**Технологии:** C++, перегрузка операторов

## Запуск

```bash
g++ main.cpp -o vector_cross
./vector_cross
```
