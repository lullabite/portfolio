# Портфолио
Учебные проекты и лабораторные работы: алгоритмы на Python и C++,
автоматизация построения чертежей в AutoCAD.

## Содержание

| Папка | Описание |
|---|---|
| `cad-automation/` | Автоматическая генерация чертежей фермы для AutoCAD (C++, DXF) |
| `cpp/labs/` | Лабораторные работы по C++: файлы, структуры, ООП, перегрузка операторов |
| `python/algorithms/` | Алгоритмические задачи на Python |
