# Minimum Number of Pushes to Type Word I (LeetCode 3014)

**Сложность:** Easy  
**Источник:** [LeetCode](https://leetcode.com/problems/minimum-number-of-pushes-to-type-word-i/)  

## Смысл задачи

Нужно набрать заданное слово на телефонной клавиатуре (кнопки 2 - 9), но мы можем сами решить, какие буквы на какие кнопки назначить.  
Каждая кнопка может содержать несколько букв; чтобы напечатать букву, нужно нажать кнопку столько раз, какой по счёту она стоит на этой кнопке (первая - 1 раз, вторая - 2 раза и т.д.).  
Задача - распределить буквы так, чтобы общее количество нажатий для слова было минимально.

## Что делает этот код

1. Подсчёт частот. Проходим по строке и вручную считаем, сколько раз встречается каждый символ.
2. Сортировка по убыванию частоты. Самые частые буквы должны получить «дешёвые» позиции (1 нажатие).
3. Распределение по 8 корзинам (кнопкам). На каждом шаге находим самую короткую корзину и кладём туда самую частую из оставшихся букв.
4. Фиксация позиций. Для каждой буквы запоминаем, на какой позиции она лежит на своей кнопке.
5. Подсчёт результата. Проходим по исходной строке и суммируем количество нажатий.
