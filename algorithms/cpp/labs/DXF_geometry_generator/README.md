# Working with structures and DXF files

Программа рисует три шестиугольника с узлами (окружностями в вершинах)
и записывает их в dxf-файл, который открывается в AutoCAD.

**Технологии:** C++, файловый вывод, формат DXF

## Файлы
- `dxf_out.cpp` — функции вывода примитивов AutoCAD (линия, окружность, текст и др.) в dxf
- `main.cpp` — построение шестиугольников, точка входа
- `output/var3_example.dxf` — пример результата

## Запуск
```bash
g++ main.cpp -o lab07
./lab07
```
Результат появится в `var3.dxf` в директории запуска.
